## Registering and updating a study

1. Agree a bounded scope and owner through an issue or discussion.
2. Create a record using the [template](experiment-template.md), retaining a stable ID and linking the exact implementation and access conditions.
3. Replace the relevant proposed entry with a link to that record, or add a distinct entry when the question differs.
4. Append execution, scoring, replay and review artifacts as they exist. Mark each actual status separately and preserve protocol changes.

Use a concise result entry: **claim; method and revision; evidence link; finding and limit; review/replay status; next action**. Keep executed outcomes separate from interpretations and planned next runs.
